## 🔍 CÓMO USAR

### **Opción 1: Ver todas las encomiendas**
```
GET /reportes/encomiendas
```

### **Opción 2: Filtrar por mes y año**
```
GET /reportes/encomiendas?mes=10&anio=2026
```

### **Opción 3: Filtrar por estado**
```
GET /reportes/encomiendas?estado=entregado
```

### **Opción 4: Combinado**
```
GET /reportes/encomiendas?mes=10&anio=2026&estado=entregado
```

### **Opción 5: Imprimir/PDF**
```
GET /reportes/encomiendas?mes=10&anio=2026&imprimir=1
```

## 🚨 SI NO FUNCIONA

### **Error 404: "No encontrado"**
```
✅ Verifica que agregaste las rutas en web.php
✅ Ejecuta: php artisan route:cache
```

### **Error 403: "No autorizado"**
```
✅ Verifica que el usuario tiene el permiso 'reportes.ver'
✅ En tinker: Auth::user()->givePermissionTo('reportes.ver')
```

### **No aparecen datos**
```
✅ Verifica que existen encomiendas en BD
✅ En tinker: App\Models\Encomienda::count()
```

### **Sin estilos (CSS)**
```
✅ Ejecuta: npm run build
✅ O en desarrollo: npm run dev
```
